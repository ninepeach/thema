i18n primitives

The built-in translator loads JSON catalogs from locales/. This English-only site uses one real key with interpolation:

{{ t "tutorial.welcome" "name" .Site.Name }}

// locales/en.json
{"tutorial":{"welcome":"Welcome to the {{name}} runtime tutorial."}}

{{ t "tutorial.welcome" "name" .Site.Name }}

views.Render(ctx, w, "pages/runtime", data,
    thema.WithLocale("en"))

WithDefaultLocale configures fallback for the Engine; WithLocale selects a locale for one Render. Lookup tries the requested locale, its base language, the default locale, then its base language; an unresolved key renders as the key. The application—not Thema—decides locale policy from cookies, preferences, headers, or other inputs.

Slots and Contributions

The note above is live output from the page.notice Slot. The Theme declares the extension point and trusted application code registers an existing template.

{{ slot "page.notice" . }}

views.Contribute("page.notice", thema.Contribution{
    ID:       "tutorial-note",
    Template: "contributions/tutorial-note",
    Order:    10,
})

The slot receives this page's root data, so the Contribution can read .Site.Name. IDs are unique within a Slot. Lower Order renders first; equal values preserve registration order. RemoveContribution(slot, id) removes a registered item and reports whether it existed.

Slots are HTML-fragment extension points. They are valid only as direct actions in HTML content—not in attributes, URLs, JavaScript, or CSS.

Refresh

The caller decides when to check external Theme resources. Thema starts no watcher, ticker, or background goroutine.

changed, err := views.Refresh(ctx)

An unchanged generation returns false, nil. A changed valid Theme is compiled and activated atomically. Existing renders may finish on the old Snapshot while new renders use the new one. If validation or compilation fails, Refresh returns an error and the last valid Snapshot continues serving requests.

Context and failure behavior

Render and Refresh accept context.Context and observe cancellation. Refresh calls are serialized while normal renders continue. Render never discovers or recompiles Theme files; it executes into an internal buffer first, so a template execution failure leaves the destination writer unchanged. A failure from the final destination writer can still produce a partial commit, as with any io.Writer.
