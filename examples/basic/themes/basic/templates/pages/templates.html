Trusted helpers

The cards use one application-owned helper. WithFuncs registers helpers needed by the initial Theme; Engine.Funcs can add or replace trusted helpers later with transactional recompilation.

thema.WithFuncs(template.FuncMap{
    "join": strings.Join,
})

{{ join .Tags ", " }}

The runtime names t, asset, and slot are reserved and cannot be replaced.

Escaping and assets

The dynamic ViewModel text “{{ .EscapedText }}” is rendered as normal text, so its angle brackets are escaped by html/template. Basic registers no raw HTML helper.

<link rel="stylesheet"
      href="{{ asset "css/app.css" }}">

asset validates the logical asset path and returns /assets/basic/css/app.css?v=<generation>. Thema generates the Theme-aware URL; this example's net/http handler serves the file.
