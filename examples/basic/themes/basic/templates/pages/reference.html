Engine options

Option values configure New before the first Snapshot is compiled.

WithDefaultLocale(locale)
Sets the built-in translator's final fallback locale; default en.
WithStrictMissingKeys()
Makes missing map keys fail execution; default behavior remains compatible with html/template.
WithAssetBaseURL(base)
Changes the built-in asset URL prefix; default /assets.
WithFuncs(template.FuncMap)
Registers trusted helpers before the initial Snapshot is compiled.

Render options

RenderOption values configure one Render call.

WithLocale(locale)
Selects a locale for one Render call without shared mutable locale state.

v0.1 provides its translator automatically; it has no public custom Translator replacement API.

Built-in template helpers

asset "css/app.css"
Returns a validated, Theme-generation-aware asset URL.
t "key" "name" value
Looks up a translation and interpolates name/value pairs as a normally escaped string.
slot "page.notice" .
Renders ordered Contributions in direct HTML content context.

Stable errors

ErrTemplateNotFound      ErrInvalidTheme
ErrInvalidPath           ErrIncompatibleTheme
ErrDuplicateContribution ErrRender
ErrRefresh

Use errors.Is to classify errors. Invalid manifests, Theme IDs, logical paths, helper names, Slot identifiers, and Contribution data are rejected. Missing templates return ErrTemplateNotFound; failed candidate refreshes also wrap ErrRefresh while retaining the active Snapshot.

Boundary and safety

Themes contain presentation resources, not Go code or server capabilities. v0.1 recognizes .html templates, direct-child JSON locale catalogs, assets, and the strict manifest. Logical paths reject traversal and filesystem names; symlinks and non-regular resources are rejected.

One active Theme supplies one coherent manifest, template, locale, and asset generation. Source names are resolved deterministically before parsing. Default limits are 1,000 templates, 8 MiB per recognized file, and 128 MiB per generation.

Thema supplies no router, middleware, static file server, bundler, filesystem watcher, or raw HTML helper. Application data and trusted functions determine template capability, while html/template provides contextual escaping.
