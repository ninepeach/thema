Start with a theme

{{ .Site.Name }} is a small Go-native theme runtime built on html/template. A theme groups its manifest, templates, and assets.

themes/basic/
├── theme.json
├── templates/
│   └── pages/
│       └── home.html
└── assets/
    └── css/
        └── app.css

Create the engine

Pass the Theme Repository and active Theme ID to New. Must is convenient during application startup.

views := thema.Must(
    thema.New("./themes", "basic"),
)

Render a logical template

The source file templates/pages/home.html is rendered by its logical name, without the extension.

err := views.Render(
    r.Context(),
    w,
    "pages/home",
    view,
)

Pass typed data

Application data remains the native root dot. Thema does not add a .Data wrapper.

type PageView struct {
    Title       string
    Description string
}

<h1>{{ .Title }}</h1>
<p>{{ .Description }}</p>

Run this example

cd examples/basic
go run .
