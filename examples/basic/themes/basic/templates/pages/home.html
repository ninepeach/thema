Start with a theme

{{ .Site.Name }} is a small Go-native theme runtime built on html/template. A Theme Repository contains one or more Theme directories; the directory name is the Theme ID.

themes/
└── basic/                 # active Theme ID
    ├── theme.json
    ├── templates/
    │   └── pages/home.html
    ├── locales/en.json
    └── assets/css/app.css

Declare the manifest

The manifest is strict. Its name, SemVer release version, and Thema contract version are required.

{
  "name": "Basic Example",
  "version": "1.0.0",
  "thema": "0.1"
}

Create the engine

Pass the Theme Repository and active Theme ID to New. Must is convenient when startup should stop on invalid Theme input.

views := thema.Must(
    thema.New("./themes", "basic"),
)

Render a logical template

The source file templates/pages/home.html is rendered as pages/home. Render accepts a context, any io.Writer, the logical name, and typed application data.

view := PageView{Title: "Getting Started"}
err := views.Render(
    r.Context(),
    w,
    "pages/home",
    view,
)

Application data remains the native root dot: {{ .Title }}, never .Data.Title.

Run this example

cd examples/basic
go run .
